# Kaizen

Personal portfolio and blog of Lucas Videla, full-stack engineer. Live at https://lucasvidela.com.ar

Astro 7, Tailwind 4, MDX-ready markdown blog, deployed on Cloudflare Workers (static assets).

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build
pnpm cf:deploy  # build + wrangler deploy
```

Project conventions and architecture live in [AGENTS.md](AGENTS.md).
